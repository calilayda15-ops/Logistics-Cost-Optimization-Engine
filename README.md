# Logistics Cost Optimization & VRP Analytics Engine
An enterprise-grade supply chain and transport cost optimization engine built with Python, Pandas, and NumPy, simulating SQL-like extraction, grouping, and analytical processing.
🚀 Project Overview
This project simulates real-world logistics operations by generating a synthetic master dataset of shipments, hubs, and vehicle types. It leverages Pandas and NumPy for high-performance vectorized calculations—such as fuel consumption, driver costs, and carbon emissions (CO_2)—without requiring an external database setup.
🛠️ Tech Stack & Skills Demonstrated
Python: Core automation and logic.
Pandas & NumPy: High-performance vectorized data manipulation, filtering, and SQL-like grouping (groupby, aggregation).
Matplotlib & Seaborn: Professional logistics data visualization.
Supply Chain Analytics: Transport cost optimization, vehicle class comparison, and carbon footprint tracking.
📊 Key Insights & Visualizations
The script aggregates data across various regional hubs and vehicle categories (e.g., Light EV Vans, Medium Duty Trucks, Heavy Freight Liners) to identify cost drivers and emission hotspots.
